# majhi build kit

Everything a coding agent needs to build majhi.

- SPEC.md: what to build, architecture, phased plan
- AGENTS.md (and CLAUDE.md, same content): how the agent should work
- design/ui-demo.dc.html: the clickable UI prototype, as a reference
- docs/: progress log and decision log the agent keeps up to date
- KICKOFF.md: the first prompt to paste

To start: make a new git repo, copy these files in, commit, open your coding agent in that folder, and paste the prompt from KICKOFF.md.
