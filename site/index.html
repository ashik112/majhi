Questions, answered.

Does my code leave my computer?
majhi runs on your computer, in Docker. Your agents send what they read to the AI company whose account you signed in with, the same as using Claude Code or Codex on their own. majhi does not send your code anywhere else.
Which AI accounts work?
Claude Code and Codex. Sign in with the subscription you already have, or paste an API key. You can add as many accounts as you like, and each client can have its own.
Do I need Docker?
Yes. majhi runs in Docker, and the install command checks that everything is ready and tells you what to fix. You also need git and Node 20 or newer. It runs on macOS, Linux and Windows through WSL2.
Is it free? Is it open source?
The source is public on GitHub, under the PolyForm Noncommercial license. It is free for noncommercial use. Using it for commercial work needs a separate commercial license from the author.
Can it push my code without me?
No. Pushing and merging wait for your click. The only exception is a client where you turned that permission on yourself.
What happens when my credits run out?
majhi marks that account as at its limit. If the agent has a backup agent on another account, the work moves there and carries on from its last checkpoint. If not, the task pauses and starts again when the limit resets.
Does it keep working when my laptop sleeps?
majhi runs on your computer, so it needs the computer to be on. If the laptop sleeps or the Wi-Fi drops, tasks pause and pick up from their last checkpoint when it wakes.

Ready to push off?

You need Docker and one command. A short trip down the river then sets up your folders, AI accounts, clients and git logins.
