On the rivers of Bengal, the majhi stands at the back of the boat with the long oar. He does not row. He reads the water, picks the line, and keeps everyone pointed at the ghat.

That is the job majhi gives you. AI agents can write real code now, but running them for real work is chaos: a subscription per client, a different git login for each, keys everywhere, and the quiet fear that one client's code ends up in another's repo. majhi turns that into a calm desk.

Meet the crew

One captain. A whole crew.

Every agent gets its own emoji, model and account. Mix Claude Code and Codex in one team.

🧑‍✈️

The captain

Sets up clients, accounts and repos when you describe them, answers the crew, and with autonomous mode on, runs the desk while you sleep.

👑

The lead

Reads your one sentence, writes the plan, and hands each piece to the right agent.

🛠️

Builders

Write the code in their own worktree and container, test it, and commit.

🔍

The reviewer

Reads every change before it reaches you, and sends it back when it is not good enough.

What it does

Everything a crew needs.
Nothing it shouldn't touch.

Built for people who run several clients at once and want the work to keep moving without babysitting.

⛵Hand it off in one sentence

"Fix the export timeout in the API, from develop." That is a whole task. The lead plans, the crew builds and reviews, and you get a report and a branch. Big work splits into subtasks across as many repos as it needs.

🌙Sail through the night

Turn on autonomous mode per workspace. The captain picks work by priority, ships it within your budget, and leaves a summary for the morning.

🧳Every client in its own boat

Accounts, agents, repos, git identity, tokens, costs and memory stay sealed per workspace. Agents never see your SSH keys.

🚢Ship from one card

Merge, squash or rebase, push, or open pull and merge requests on GitHub, GitLab and Bitbucket. Conflicts are one click.

👀Watch the water

See the plan and every file change live. Stop a turn, queue a message, open VS Code or Cursor, and get a live preview per task.

🔔Only calls you when it matters

One bell for approvals, questions and blocked work. You choose what needs your click, from careful to hands-off.

🛟It does not sink

Sleep, Wi-Fi drops, usage limits, a refused request: agents pause and resume on their own, and stuck tasks wake the lead.

🧠It remembers your codebase

Lasting facts from each task are kept per repo and brought back next time, so agents stop relearning the same quirks.

Get on board

Two commands.

You need Docker (Docker Desktop or OrbStack) on a Mac. Linux and Windows through WSL2 are on the way.

# clone and start
git clone https://github.com/ashik112/majhi.git && cd majhi
make up    # opens on http://127.0.0.1:7070
1. Take the river journey

Pick your project folder, sign in your AI account, add your clients.

2. Connect git

Sign each workspace in to GitHub, GitLab or Bitbucket, then clone or start projects.

3. Hand off the first task

One sentence. The crew takes it from there. Updates after that are one click.
